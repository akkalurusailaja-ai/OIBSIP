# Customer Segmentation Analysis
Oasis Infobyte Data Analytics Internship - Level 1, Task 2

## What I did
- RFM analysis (Recency, Frequency, Monetary) for 434 customers
- Descriptive statistics: average purchase value, frequency, customer lifetime value
- Standardised features with StandardScaler
- Elbow Method to choose K (K=3)
- K-Means clustering with 2 scatter plots and a customers-per-cluster bar chart
- Cluster profiles and a marketing action for each segment

## Segments
- Cluster 0 (93 customers): loyal high spenders
- Cluster 1 (143 customers): inactive, at-risk customers
- Cluster 2 (198 customers): recent average customers
